## انتشار روی GitHub Pages
1. یک Repository جدید در GitHub بساز.
2. هر 4 فایل بالا را در ریشه Repository آپلود کن.
3. از Settings > Pages وارد بخش GitHub Pages شو.
4. در Build and deployment، گزینه Deploy from a branch را انتخاب کن.
5. Branch را روی main و پوشه را روی / (root) بگذار و Save کن.
6. لینک ساخته‌شده را روی NFC خودت ثبت کن.

نکته: شماره تلفن‌ها و شبکه‌های اجتماعی داخل این سایت عمومی هستند.
